HART PRIDE
Each card is a photo album. In the Photos tab of the spreadsheet (SITE_CONFIG.sheets.photos in js/config.js), each row is one album: Team, Caption, and a Folder path pointing to a folder of photos in your GitHub repo — e.g. Photos/OpeningDay. Upload all the photos for that event into that folder and they'll all show up automatically when someone clicks the card.
